# AGI针灸机器人（仿真版）
> Hackathon参赛项目｜单人开发｜纯仿真，无实体硬件

## 项目简介
传统针灸高度依赖医师经验，穴位定位存在主观性。本项目基于AGI视觉能力识别人体体表穴位，输出穴位坐标，传递给机械臂仿真引擎，自动控制机械臂完成定位与针刺动作。
本作品仅为仿真原型，用于技术验证，不用于真实医疗。

## 技术架构
1. 视觉模块：调用AGI大模型，识别人体图像，输出穴位像素坐标
2. 机器人仿真模块：Python + PyBullet 6轴机械臂仿真
3. 数据流：人体图片 → AGI识别穴位 → 坐标传输 → 逆运动学求解 → 机械臂移动、模拟进针

## 功能（最小Demo）
- 识别人体局部图像，识别1~3个穴位（合谷、足三里）
- 机械臂仿真运动，自动移动到目标穴位，完成针刺仿真动作

## 环境依赖
python>=3.9
pybullet
pillow
requests
## 运行说明
1. 安装依赖：`pip install pybullet pillow requests`
2. 准备人体测试图片，放入项目目录
3. 运行主程序：`python main.py`
